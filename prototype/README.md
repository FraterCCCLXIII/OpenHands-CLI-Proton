# Prototype

UI experiments and prototypes for the OpenHands CLI.

## Run

```bash
openhands prototype
```

Or from the project root:

```bash
uv run openhands prototype
```

## Contents

- **openhands_cli.py** — Standalone Textual app with experimental screens and dummy flows
- **openhands_cli.tcss** — Styles for the prototype
- **MIGRATION.md** — How to port UI changes to production and add dummy flows
